# Заметки по проекту

## Цель проекта

Основная цель — разработка функционального прототипа интернет-магазина чая "Infinitea" с фокусом на освоение профессиональных инструментов DevSecOps.

**Практические задачи и цели:**
* Освоение Git и командной разработки: Работа с ветками, симуляция и разрешение конфликтов слияния, оформление Pull Request'ов.
* Работа в Linux Ubuntu
* Работа с Dockerfile и Docker Compose
* Проектирование архитектуры 
* DevOps
* Составление отчётов в формате Markdown.

### Используемые технологии
Планируется запуск проекта при поддержке следующих технологий:
*   **Операционная система:** Linux Ubuntu;
*   **Контейнеризация:** Docker & Docker Compose;
*   **База данных:** PostgreSQL;
*   **Система управления версиями:** Git.
