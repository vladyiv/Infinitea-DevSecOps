# Учебный проект по теме "Мини-магазин чая Infinitea"

## Навигация

### Проект представлен в виде git-репозитория со следующими файлами и папками:

- README.md — основная информация по проекту;
- Project-Notes.md — заметки по проекту;

- Infinitea.Api — папка с файлами проекта;

### Коммиты осуществляются в пяти ветках
- main – основная ветка;
- develop — ветка для сборки проекта;
- feature/readme — ветка для редактирования файлов README и project-notes
- feature/api-plan — ветка для редактирования файла api-plan;

## Основная информация

### Описание системы
API-приложение "Мини-магазин чая Infnintea" с базой данных на основе образа PostreSQL. В качестве графической оболочки выступает Swagger UI, доступный в браузере после запуска docker-container (инструкция по запуску ниже).

### Инструкция запуска
#### Вариант с Dockerfile
Запуск приложения осуществляется через Docker Container.
Необходимо иметь установленные Git и Docker
1. Клонировать репозиторий:

`git clone https://github.com`

`cd Infinitea-DevSecOps`

2. Собрать образ:

`docker build -t infinitea-api .`

3. Запустить образ:

`docker run -p 8080:8080 infinitea-api`

Флаги:
- -p для проброса порта
- --name для задания имени образу
- -d для запуска в фоновом режиме (позволит выполнять следующие шаги в этом же окне терминала без необходимости открывать новое)
- --rm для удаления контейнера после завершения работы

4. Проверить работу контейнера:

После запуска API будет доступно по адресу `http://localhost:8080` в браузере и в терминале через `curl`

Вывод логов:

`docker logs infinitea-app`

Завершение работы:

`docker stop infinitea-app`

Удаление контейнера:

`docker rm infinitea-app`

#### Вариант с docker-compose
Запуск приложения осуществляется через docker-compose.yml.
Необходимо иметь установленные Git и Docker Compose
1. Клонировать репозиторий:

`git clone https://github.com`

`cd Infinitea-DevSecOps`

2. Собрать образ:

`docker compose build .`

3. Запустить образ:

`docker compose up`

Флаги:
- `--build` для пересборки перед запуском
- `-d` для запуска в фоновом режиме (позволит выполнять следующие шаги в этом же окне терминала без необходимости открывать новое)

4. Проверить работу контейнера:

После запуска API будет доступно по адресу `http://localhost:8080/index.html` в браузере и в терминале через `curl`

Вывод логов:

`docker compose logs`

Завершение работы:

`docker compose down`
