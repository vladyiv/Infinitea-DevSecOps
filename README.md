## Основная информация

### Описание системы
API-приложение "Мини-магазин чая Infnintea" с базой данных на основе образа PostreSQL. В качестве графической оболочки выступает Swagger UI, доступный в браузере после запуска docker-container (инструкция по запуску ниже).

### Схема архитектуры
*Проект находится на этапе проектирования.*

### Список сервисов
#### Товары
- Получение списка всех товаров из базы данных;
- Получение информации о товаре по ID;
- Добавление нового товара;
- Изменение существующего товара по ID;
- Удаление товара по ID.

###  Корзина и Заказы
- Добавление товара в корзину;
- Оформление заказа;
- Просмотр корзины;
- Удаление товара из корзины.

###  Пользователи
- Регистрация нового пользователя;
- Вход в аккаунт;
- Выход из аккаунта;
- Получение аккаунта по username;
- Изменение данных пользователя;
- Удаление пользователя.
