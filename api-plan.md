# План разработки API. Что должно будет уметь приложение:

### Товары
* Получить список всех товаров (вывод на главную страницу);
* Получить подробную информацию об одном конкретном товаре по его ID;
* Добавить новый товар.

###  Корзина и Заказы
* Добавить товар в корзину;
* Посмотреть корзину;
* Оформить заказ.

###  Пользователи
* Регистрация нового пользователя;
* Вход в аккаунт.

#### Информация будет обновляться по ходу работы над проектом.
