# План разработки API. Что должно будет уметь приложение:

### Товары — сервис полностью реализован!
- [X] GET: Получить список всех товаров (вывод на главную страницу);
- [X] GET: Получить подробную информацию об одном конкретном товаре по его ID;
- [X] POST: Добавить новый товар;
- [X] PUT: Изменить существующий товар;
- [X] DELETE: Удалить товар.

###  Корзина и Заказы
- [ ] POST: Добавить товар в корзину;
- [ ] POST: Оформить заказ;
- [ ] GET: Посмотреть корзину;
- [ ] DELETE: Удалить товар из корзины.

###  Пользователи
- [ ] POST: Зарегистрировать нового пользователя;
- [ ] POST/GET: Войти в аккаунт;
- [ ] POST/GET: Выйти из аккаунта;
- [ ] GET: Получить аккаунт по username;
- [ ] PUT: Изменить данные пользователя;
- [ ] DELETE: Удалить пользователя.

#### Информация будет обновляться по ходу работы над проектом.
